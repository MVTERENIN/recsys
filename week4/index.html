Two-Tower MovieLens 100K Retrieval Demo

Usage Tips:
• Loading data fetches and parses MovieLens 100K files.
• Training runs fully in browser; typical training may take a few minutes depending on settings.
• After training, a 2D projection of item embeddings is shown.
• Testing shows side-by-side top-10 rated movies, deep learning recommendations, and content-based recommendations.
• To host on GitHub Pages, place index.html, app.js, two-tower.js in root and data/ folder with the three dataset files.
• No server needed; fully client-side TF.js demo.
